# V3 — Comparação das 257 árvores: Meta/WRI × C1–C6 × logarítmica × potência recalibrada

**A primeira coluna contém a altura de dossel estimada pelo Meta/WRI CHMv2 no pixel correspondente ao ponto de referência.** A tabela apresenta uma linha para cada um dos **257 pontos originais** da Area1, Caxias do Sul. Todos os cálculos usam a mesma **área do superpixel Quickshift**, que **não é necessariamente a área de copa da árvore**.

**Fórmulas C1–C6:** são as seis **versões potenciais históricas** do notebook original, `I = a × A^b`; **não são alturas validadas em metros**. Também existem seis versões lineares (`I=a+b×A`) no [CSV completo](v3_comparacao_completa_c1_c6_pot_linear_log_meta_257.csv).

**Logarítmica ajustada ao pixel Meta:** `H = 1,02061062 + 0,43611553 × ln(1 + A)`.

**Potencial ajustada ao pixel Meta (fórmula destacada na imagem):** `H = 1,36838076 × A^0,17089464` (arredondada: `1,3684 × A^0,17089`).

Os coeficientes dos dois modelos ajustados foram obtidos **usando os 257 pontos**; por isso os valores abaixo **não constituem teste independente**. Para validar a generalização, usar os testes espaciais fora da amostra [já executados](v3_meta_calibracao_validacao_espacial.csv). Meta/WRI também é previsão, não altura medida em campo. A relação proposta anteriormente `H=c+a×D_copa^b` **não foi incluída como altura individual**, pois não temos diâmetros reais de copa nem coeficientes calibrados a essa variável; substituir o diâmetro por um equivalente derivado de superpixel não resolveria essa limitação.
